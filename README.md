# Watermark Telegram Bot

Бот наносит текстовый водяной знак на фото элегантным курсивным шрифтом
(Playfair Display Italic, поддерживает кириллицу) по диагонали.

Работает в формате диалога:
1. Пользователь присылает **текст** — это и будет водяной знак.
2. Пользователь присылает **фото** — бот возвращает его с нанесённым текстом.
3. После результата можно сразу прислать ещё фото с тем же текстом
   или поменять текст — кнопками под сообщением.

## Установка

```bash
pip install -r requirements.txt
```

Шрифт `fonts/PlayfairDisplay-Italic.ttf` уже входит в комплект.

## Настройка

1. Получи токен бота у [@BotFather](https://t.me/BotFather).
2. Скопируй `.env.example` в `.env` и впиши токен:

```
BOT_TOKEN=твой_токен
```

## Запуск

```bash
python bot.py
```

## Команды для управления
Команды:
- `/start` — начать заново и задать текст
- `/help` — краткая инструкция
- `/cancel` — отменить текущее действие

## UX-детали

- Меню команд бота настроено через `set_my_commands`
- Во время обработки фото бот показывает статус «печатает фото» и
  сообщение «⏳ Наношу водяной знак…», которое затем удаляется и
  заменяется результатом — без долгого ожидания вникуда.
- После результата — инлайн-кнопки для продолжения работы без
  необходимости лишний раз вызывать `/start`.
- Текст водяного знака хранится в `context.user_data`, то есть отдельно
  для каждого пользователя в рамках сессии (если бот перезапустится —
  пользователю нужно будет снова прислать /start).

## Настройки внешнего вида

В начале `bot.py`:

```python
FONT_PATH = os.path.join(FONTS_DIR, "PlayfairDisplay-Italic.ttf")
FONT_SIZE_RATIO = 0.07     # размер шрифта = 7% от меньшей стороны фото
OPACITY = 170              # прозрачность текста (0..255)
SHADOW_OPACITY = 90        # прозрачность тени под текстом
ROTATION_DEGREES = -30     # наклон надписи
TILE_SPACING_RATIO = 0.55  # как часто повторять надпись
```

Хочешь другой шрифт — клади файлы `*.ttf`/`*.otf` в папку `fonts/`
