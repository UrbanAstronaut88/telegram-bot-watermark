# Watermark Telegram Bot

Бот принимает фото и возвращает его с наложенным водяным знаком.
Владелец бота может в любой момент поменять картинку вотермарки.

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

1. Получи токен бота у [@BotFather](https://t.me/BotFather).
2. Узнай свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Скопируй `.env.example` в `.env` и заполни:

```
BOT_TOKEN=твой_токен
OWNER_ID=твой_id
```

4. (Опционально) Замени стартовый `watermark.png` на свою картинку —
   просто положи файл `watermark.png` рядом с `bot.py` ещё до запуска,
   либо поменяй её прямо через бота (см. ниже).

## Запуск

```bash
python bot.py
```

## Как пользоваться

- **Любой пользователь**: отправляет боту фото → получает то же фото
  с водяным знаком в правом нижнем углу.
- **Владелец бота** (тот, чей ID указан в `OWNER_ID`):
  1. Отправляет команду `/setwatermark`.
  2. Присылает картинку (лучше PNG с прозрачным фоном).
  3. Бот сохраняет её как новый водяной знак — он сразу же
     начинает применяться ко всем последующим фото от пользователей.

## Настройки вотермарки

В начале `bot.py` есть параметры, которые можно менять:

```python
WATERMARK_SCALE = 0.25     # ширина вотермарки = 25% ширины фото
WATERMARK_OPACITY = 0.6    # прозрачность 0..1
WATERMARK_MARGIN = 20      # отступ от края в пикселях
```

Позиция сейчас — правый нижний угол. Если нужно поменять расположение
(например, по центру или вообще замостить всё изображение) — скажи,
доработаю.

## Хостинг

Бот использует polling (`app.run_polling()`), поэтому его можно просто
держать запущенным на любом сервере / VPS / Raspberry Pi, без необходимости
настраивать webhook. Для постоянной работы удобно запускать через
`systemd`, `screen`, `tmux` или Docker.
